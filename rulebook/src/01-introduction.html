Introduction

This game is a work-in-progress system for miniature war gaming in the Bronze Age through the end of Classical Antiquity. This is not a simulation for recreating massive battles from history, but an anachronistic and ahistorical miniature game meant for smashing together units from different eras and locales. The goal of this game is to utilize the large number of historical figures designed for collectors, to create a fun and exciting miniature game that has meaningful and tactical depth. This game is clearly inspired by Game Workshop’s Warhammer Ancient Battles game, but seeks to take tray-based miniature wargaming a step further, using inspiration from a plethora of popular miniature and board games.
