Supplies Needed to Play

First and foremost, each player needs miniatures, bases, and then trays for their Closed Order units. Each player should decide on a value from which they each make an Army List, with standard games at 2000 points per side, or 1250 points per player in 2v2 games. Special scenarios may use different values.

Each player will need a Command deck, a set of 6 cards that they select for their army.

Players also need a measuring instrument, in Inches, as well as a Turning Template and a Corner Marker (a small 90° template, used to keep a tray’s position when it turns About Face). Then they also need a decent quantity of six-sided dice. This game does not use dice of other denominations. And finally, this game uses Order Tokens to indicate the order in which they activate their units. The trays, bases, template, and tokens can all be 3D printed from the provided STL files.
