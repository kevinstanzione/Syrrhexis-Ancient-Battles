# Terrain bases

Printable bases for the small terrain features placed by Command cards. Each is cut to the exact footprint on its card, 3 mm thick with a 1.2 mm chamfered top edge, so a model can be glued on top and the piece still measures true. Large terrain (Dense Brush, Crumbled Ruins, Flooded Field and so on) and Major Terrain use felt, so they have no bases.

Regenerate with `python3 terrain/make_bases.py` (needs `trimesh`).

Tips:
- Print flat, chamfer up. No supports needed.
- Glue the model (for example a Meshy print scaled to fit) on top; texture or flock the exposed top surface.
- A model may overhang the base slightly, but the base is what counts on the table: measure from its edge.
