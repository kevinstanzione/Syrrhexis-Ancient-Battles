# Syrrhēxis movement trays

3D-printable trays for every Closed Order formation in the list builder. Each tray holds its bases touching in ranks (front to back) and files (across the frontage), with every model facing forward. Open Order units don't use trays.

Recess clearance 0.4 mm, border 3.0 mm, floor 1.4 mm, recess depth 2.0 mm.

To regenerate after army changes: `pip install trimesh manifold3d`, then `python trays/make_trays.py`.
